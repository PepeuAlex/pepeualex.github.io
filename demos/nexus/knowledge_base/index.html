Resolving VPN Connectivity Issues (Error 412)

By Sarah Jenkins
Updated 2 days ago KB0019284

This guide provides step-by-step instructions for resolving the common "Error 412: Authentication Failed" issue encountered when connecting to the corporate Cisco AnyConnect VPN client.

info Root Cause

This error typically occurs when the local machine's security certificate cache is out of sync with the primary authentication server following a password reset.

Resolution Steps

  1. Open the Cisco AnyConnect client and click the gear icon to access settings.
  2. Navigate to the Preferences tab.
  3. Check the box for "Clear cached credentials on exit".
  4. Close the client completely (ensure it is not running in the system tray).
  5. Open Command Prompt as Administrator and run the following command:
    ipconfig /flushdns && certutil -urlcache * delete
  6. Restart the VPN client and authenticate using your current Active Directory credentials.
